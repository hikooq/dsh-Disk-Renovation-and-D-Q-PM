## 一、技术栈与页面性质

| 项 | 结论 | 证据 |
|---|---|---|
| 渲染方式 | CSR，客户端 JS 渲染整页 | web_fetch 仅得 title；两篇复刻文章均基于 CSR 行为反推 |
| 框架 | Vue（官网早期 Nuxt/Vue 系；复刻用 Vue3 `<script setup>` + computed） | 复刻文章代码 |
| 深链 | URL query `?char=N` 直接定位到第 N 个角色 | 页面 URL 本身；本地 main.js 已用 `history.replaceState` 同步 |
| 路由变量 | 路径段 `/character/{region}` 表示地区（mondstadt / fontaine…） | 文中引用了 `/character/fontaine?char=1` |

## 二、页面级功能清单（已确认）

### 1. 顶部导航栏（header）
- 背景音乐开关图标（`music-header-off.png` ↔ `music-header-on.png`，点击切换并播放/暂停循环 BGM）—— 对应本地 `#musicBtn` + `#bgm`。
- 「原神」Logo（`logo-header.png`）。
- 主菜单按官网写法两字词用空格撑开字距：首页 / 新闻 / 角色 / 世界 / 漫画 / 社区 / 赛事 / 充值中心；当前页「角 色」高亮。
- 右侧：成长关爱系统、登录（`like-header.png`、`user-header.png`）。
- 官网另有语言切换（简繁/多语）等入口，本地复刻未做。

### 2. 左侧地区列表（sidebar）
- 8 项：蒙德城、璃月港、稻妻城、须弥城、枫丹廷、纳塔、至冬、敬请期待（本地 CITIES 数据）。
- 点击切换地区 → 换整套角色数据；未开放地区置灰不可点（`character__city--disable`）。
- 本地素材只有蒙德，其余按 `ready:false` 半透明禁用。

### 3. 主视觉区（character__main）
- 三层背景：
  - `bg1.jpg` 白天蒙德城（1920×1080）
  - `bg2.jpg` 黄昏蒙德城（1920×1080）
  - `bg3.png` 白底 + 灰色斜条纹装饰层（2300×1080），元素相对它定位
- **双背景交替 + 呼吸式放大**（官网标志性效果，必须逐字保留参数）：
  ```css
  .role-bg1 { animation: breath 80s infinite linear; opacity: 1; }
  .role-bg2 { animation: bg-change 15s infinite linear, breath 80s infinite linear; opacity: 0; }
  @keyframes bg-change { 48%{opacity:0} 50%{opacity:1} 98%{opacity:1} 100%{opacity:0} }
  @keyframes breath { 0%{transform:scale(1)} 50%{transform:scale(1.2)} 100%{transform:scale(1)} }
  ```
  即第一张永远在、持续 80s 缩放；第二张每 15s 一个循环，只在 48%→100% 之间淡出，实现"若隐若现"的双图交替。
- 角色切换立绘动画：所有立绘初始定位在屏幕外（`right` 偏出 + `opacity:0`），当前角色加 `.show-background-pc{right:0;opacity:1;transition:all .3s}`，其余 `.hide-background` 让开 → 实现"旧角色滑出、新角色滑入"。
  - 移动端同样机制，`right: 445px` 为可见位置。
- 元素徽记（`role-type-bg/{name}.png`，400×420）衬在角色名后方。
- 角色名艺术字（`role-name/{name}.png`，600×162，白色描边字）。
- CV 条：`CV: {中文声优}` + 语音播放按钮 + 中/日 语音切换开关（两段式 `character__sbtn--active`）。
- 角色简介文本，保留官网换行（`\n` → 换行）。
- 台词气泡（`role-prompt-book/{name}.png`，450×190）。

### 4. 底部角色卡片条（character__page）
最复杂的交互，官网规则（复刻文章逐条给出）：
- 结构：外层可视窗口 `overflow:hidden`（PC 宽 830px，移动端 320px）→ 内层横向滚动容器 `role-inner`（`left` 位移）→ 一个个角色卡（头像 `role-pic-min` 106×106 + 名字）。
- PC 单卡占位 = **110px 宽 + 34px margin = 144px**（文中一处写成 145，以 144 为准）。
- 位移规则（`moveDistance` computed）：
  1. `index < 3` → `left = 0`，只切激活态不位移；
  2. 中间 → `left = (index - 2) * -144`，让当前卡**始终停在第 3 个可见位**；
  3. `index > length - 4`（末 3 张）→ `left = (length - 6) * -144`，停在倒数第 6 个。
- 箭头翻页首尾循环：`lastPage` 于 index 0 时跳到 `length-1`；`nextPage` 于末位跳回 0。
- 点击任意卡片 → `handleRoleSwitchPC(index)`，切换并关闭位移过渡（`isCloseTranstion`）。
- 选中卡背景用 `backgroundPosition: '0 -132px'` 换底图态，名字 `#000` vs `#fff`。
- 移动端：触摸拖动实时跟手（`recordLastMove + moveDistanceX`），松手按 **64px 步长吸附**（`Math.round(x/64)*64`），限位 `rightMaxValue = (length - 5) * -64`；卡片数 < 5 时不位移。
- 点击 / 滑动冲突判定：`endX - startX === 0` 视为点击，否则视为滑动（`e.preventDefault()`）。
- 官网另有滚轮/键盘切换（本地补了 `ArrowLeft`/`ArrowRight` 与 `wheel` + 420ms 节流）。

### 5. 换角色时联动更新（本地 `go(i)` 已验证对齐）
一次切换同时更新：大立绘、名字艺术字、台词气泡、元素徽记、CV 文案、简介 HTML、卡片高亮、卡片条滚动位置、`?char=N` URL。
- 淡入重播技巧：`transition:none → opacity:0 → 强制重排(void offsetWidth) → 还原`，保证默认元素始终可见（JS 失效也不丢内容）。
- 切换后 `scrollTo({left, behavior:'smooth'})`，`left = clamp((current-2)*144, 0, scrollWidth-clientWidth)`，与上面第 3 个可见位规则一致。

## 五、留给下一个会话的关键结论

1. 直接抓官网 HTML 拿不到内容，**必须按 CSR 理解**；想要数据只能从 DOM 实测或第三方复刻源码反推。
2. 官网效果的两个数值锚点：**卡片 144px 步长（110+34）**、**背景 80s 缩放 + 15s 双图交替**。
3. 本地项目已经复刻了 PC 端角色切换的主链路，**最值得补的是移动端触摸滑动、真实语音（中日两套）、载入转场**。
