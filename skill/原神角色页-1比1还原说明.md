## 二、素材缺口与处理方式（已按"不外补"处理）

1. **语音文件**：素材包里没有 `.mp3` 语音，官网的日语/中文配音无法复现。
   约定目录已写好：`images/voice/zh/角色名.mp3`、`images/voice/jp/角色名.mp3`，
   丢进去即可自动生效；没有文件时按钮会抖动并提示，不会静默失败。
2. **角色数量 23 vs 官网 26**：素材只有 23 位蒙德角色（缺达达利亚等），角色表以素材为准，卡片条位移按 23 张计算，不会露出空位。
3. **7 个未开放地区**：璃月/稻妻/须弥/枫丹/纳塔/至冬/敬请期待全部置灰、不可点（官网此时也是未开放态），素材仅覆盖蒙德。
4. **移动端布局为按比例重建**：官网移动端另有一套切图，这里用同一批 PC 素材按比例重排（360~768px 生效），观感接近但非逐像素。
5. **`.png` 实际多为 WebP 编码**：浏览器按内容嗅探正常显示，无需改名。

## 三、如何自测

直接双击 `yuan.html` 即可打开（`file://` 下地址栏参数改写会被浏览器禁止，代码已静默跳过，其余交互不受影响）。

推荐用本地静态服务，行为最接近官网：

```bat
cd /d D:\shizhan\原神
python -m http.server 8080
```

然后访问 `http://127.0.0.1:8080/yuan.html?char=0`。

自测清单：

- [ ] 箭头 / 点卡片 / 键盘 ← → / 滚轮 均能切换，首尾循环不断裂
- [ ] 当前卡始终停在第 3 个可见位，末尾 3 张时卡片条不再左移
- [ ] 切角色时立绘右滑入、信息区上浮、气泡晚 0.3 秒出现
- [ ] `?char=5` 打开落在可莉，切换后地址栏参数同步，F5 与后退保持同一角色
- [ ] 手机（或 DevTools 375px 模拟）：拖动跟手、松手吸附、到头不越界、拖动不会误触点击
- [ ] 中/日开关切换有提示；语音按钮无素材时抖动并提示
- [ ] 音乐按钮能开关 `bgm.mp3`（被自动播放策略拦截时会提示再点一次）
